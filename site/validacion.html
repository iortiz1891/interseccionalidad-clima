¿Cómo funciona? (leer una vez)
  • Vas a leer el resumen de cada trabajo y codificar tú mismo la rúbrica, sin ver el puntaje del modelo (codificación a ciegas).
  • Primero el criterio de entrada (gate); si es «No», el trabajo no aplica interseccionalidad de forma relacional y su puntaje es 0 (igual puedes anotar los demás criterios si quieres).
  • Para cada criterio elige No / Parcial / Sí. Hay una pregunta guía bajo cada uno.
  • Tu avance se guarda solo en este navegador. Puedes cerrar y reanudar.
  • Al terminar, pulsa «Ver concordancia con el LLM» para el κ de Cohen, y exporta el CSV para enviarlo.
